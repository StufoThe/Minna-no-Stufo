Rahasia Membongkar Pola Pikir Pembuat Soal: Bab 50 Offering vs Self-Action

Semua nomor yang kamu salahkan di lembar ujian kemarin memiliki benang merah yang jelas: salah membedakan kata asli Jepang (Wago - お) vs serapan China (Kango - ご), serta tertukar antara tindakan diri sendiri (Kenjougo) vs menawarkan jasa (Offering) vs menghormati atasan (Sonkeigo).

🛡️ PANDUAN BAB 50: MERENDAHKAN DIRI (SAYA MELAPOR) vs MENAWARKAN JASA (OFFERING)

1. SAYA MELAPOR / BERTINDAK (MERENDAHKAN DIRI)

ATURAN: Wajib dahulukan Kata Khusus Kenjougo! Jika tidak ada kata khusus, gunakan pola お/ご～します.

• Besok saya yang pergi: 私が 参ります (Bukan いきます / かいきします).
• Saya makan kuenya: 美味しく いただきました (Bukan 召し上がりました).
• Saya berada di resepsionis: 受付に おります (Bukan います / いらっしゃいます).
• Saya melihat dokumen: 資料を 拝見します (Bukan 見ます / ご覧になります).
• Saya tidak tahu: 存じません (ぞんじません).
2. SAYA MENAWARKAN BANTUAN / JASA (OFFERING)

ATURAN: Saya berbuat untuk meringankan lawan bicara. Gunakan pola:
• Wago: お + KK + しましょうか / いたします
• Kango (2 Kanji): ご + KB + いたします

• Bawa koper bos: お荷物を お持ちしましょうか (DILARANG: お持ちになりますか).
• Pandu ke ruangan: 会議室へ ご案内いたします (Kango 2 Kanji).
• Menjelaskan dokumen: 資料を ご説明いたします (Kango 2 Kanji).
• Memperkenalkan produk: 新製品を ご紹介します (Kango 2 Kanji).
⚡ Rumus 1 Detik Membedakan Akhiran di Pilihan Ganda:

• Subjek SAYA (merendahkan/menawarkan) → Cari akhiran ～します / ～いたします / kata khusus Kenjougo.
• Subjek BOS (dihormati) → Cari akhiran ～になります / kata khusus Sonkeigo.
• Mempersilakan BOS (perintah santun) → Cari akhiran ～ください (contoh: お入りください, ご利用ください).

⚡ RUMUS 3 DETIK: KAPAN PAKAI お (O) vs ご (GO)? (PENYEBAB SALAH NO. 23, 28, 32, 34, 39!)

1. WAJIB お (O) = KATA ASLI JEPANG (和語 - Wago)

CIRI KHAS: Kata kerja golongan 1 & 2 yang ada buntut hiragana (bentuk -masu) atau kata benda kuno Jepang.

• 持ちます → お持ちします / になります
• 帰ります → お帰りに なります
• 読みます → お読みください
• 入ります → お入りください (Silakan masuk!)
• 待ちます → お待ちください
• 座ります → お座りください / お掛けください
2. WAJIB ご (GO) = DUA KANJI DERET (漢語 - Kango)

CIRI KHAS: Gabungan 2 kanji tanpa hiragana di tengahnya (biasanya Kata Kerja Golongan 3 ~shimasu).

• 案内 (No. 23) → ご案内 いたします (Bukan お案内!)
• 説明 (No. 28 & 39) → ご説明 になります / いたします
• 利用 (No. 32) → ご利用 ください (Bukan お利用!)
• 紹介 (No. 34) → ご紹介 します (Bukan お紹介!)
• 連絡 → ご連絡 いたします
• 相談 → ご相談 します
⚠️ 5 Pengecualian Emas Favorit Pembuat Soal (2 Kanji tapi pakai お):

Guru suka menjebak dengan kata yang sering dipakai sehari-hari: お電話, お時間, お食事, お返事, お部屋. Di luar ini, jika 2 kanji deret golongan 3, hajar dengan ご (GO)!
